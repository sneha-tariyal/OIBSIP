# Online Retail Data Cleaning

## Objective

To clean an online retail dataset and prepare it for further analysis.

## Tools Used

* Python
* Pandas
* Jupyter Notebook

## Data Cleaning Steps

* Inspected dataset structure, missing values, and data types.
* Handled missing values.
* Identified and removed duplicate records.
* Checked invalid prices and negative quantities.
* Detected potential outliers using the IQR method.
* Compared data quality before and after cleaning.

## Files Included

* `Online_Retail_Data_Cleaning.ipynb` — notebook containing the cleaning code and explanations.
* `Online_Retail_Cleaned.csv` — cleaned dataset exported after processing.

## Output

The cleaned dataset has no missing values or duplicate rows and is saved as a CSV file for further analysis.

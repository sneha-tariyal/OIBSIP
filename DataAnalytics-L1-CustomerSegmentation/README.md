# Customer Segmentation Analysis

This is my Task 2 project for the OASIS INFOBYTE Data Analytics Internship.

In this project, I worked on customer segmentation using the Olist e-commerce dataset. The main aim was to understand customer purchasing behaviour and group customers based on their buying patterns.

I used Python to clean and prepare the data, calculate RFM values (Recency, Frequency and Monetary), and apply K-Means clustering to create customer groups.

### Tools Used
- Python
- Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

### What I Did
- Loaded and inspected the dataset.
- Checked and handled missing values.
- Combined customer, order and payment data.
- Calculated customer purchasing metrics.
- Used RFM features for customer segmentation.
- Applied StandardScaler and K-Means clustering.
- Used the Elbow Method to select the number of clusters.
- Created visualizations and studied each customer group.
- Added marketing suggestions for each segment.

### Results
I divided 96,095 customers into 3 groups:

- **Cluster 0:** High-value customers who make repeat purchases.
- **Cluster 1:** Customers who have not purchased for a longer time.
- **Cluster 2:** Customers who purchased more recently but mostly made one purchase.

Based on these groups, I suggested different marketing strategies to improve customer engagement and encourage repeat purchases.
